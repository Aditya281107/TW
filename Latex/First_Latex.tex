\section{Equations and Citations}

Einstein's mass--energy equivalence, $e = mc^{2}$, was published in \citet{einstein1905}.

The Schr\"{o}dinger equation \citep{schrodinger1926} is:
\begin{equation}
  \label{eq:schrodinger}
  i\hbar \frac{\partial}{\partial t} \Psi(\mathbf{r}, t)
  = \left[ -\frac{\hbar^{2}}{2\mu} \nabla^{2} + V(\mathbf{r}, t) \right]
  \Psi(\mathbf{r}, t)
\end{equation}

Equation~\ref{eq:schrodinger} describes how the quantum state of a system changes with time.
